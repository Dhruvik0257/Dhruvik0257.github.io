# High IQ
High IQ is an Android personal finance application for managing cards, bills, transactions and investment holdings.
## Features
- **Wallet:** organize credit and debit cards with masked previews and saved benefit notes.
- **Bills and reminders:** track statements, payment records and upcoming due dates.
- **Transactions:** review spending and user-configured cashback estimates.
- **Holdings:** connect to Angel One through SmartAPI to view portfolio holdings.
- **Friends:** keep records of lending, borrowing and settlements.
## SmartAPI integration
The current High IQ integration authenticates directly using PIN and TOTP. This website is an informational page; it does not implement browser-based login or an authentication callback.
## Privacy
This static website has no credential forms or analytics. Never submit card details, PINs, TOTP codes or API keys here.
